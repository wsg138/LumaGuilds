# V3 asset integration

V3 replaces the flat abstract category glyphs with Minecraft-native object compositions while keeping the panel/card geometry in the background texture.

The icon canvases remain transparent. The UI background remains responsible for framing, spacing and button wells, so the richer icons still read as one interface rather than standalone illustrations.

The redesign also introduces separate 6-row background families for Home, Grid, List, Detail and Danger screens. These let dense rosters, settings/detail pages and confirmation pages share the same frame/palette without forcing every screen into the home dashboard geometry.
